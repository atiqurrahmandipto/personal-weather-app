# আবহবার্তা (AbohoBarta) ⛅ বাংলাদেশ আবহাওয়া পূর্বাভাস পোর্টাল

**আবহবার্তা (AbohoBarta)** হলো একটি আধুনিক, দ্রুত এবং নান্দনিক ওয়েদার অ্যাপ্লিকেশন — যা বিশেষভাবে বাংলাদেশের আবহাওয়া, ৮টি প্রশাসনিক বিভাগ এবং ৬৪টি জেলার বিস্তারিত পূর্বাভাস দেওয়ার জন্য তৈরি করা হয়েছে।

Crafted with clean **HTML5**, **CSS3 (Vanilla CSS + Glassmorphism)**, and **JavaScript (ES6+)**.

---

## 🇧🇩 মূল বৈশিষ্ট্যসমূহ (Key Features)

- 🏛️ **৮টি বিভাগ ও প্রধান জেলাসমূহ**: এক ক্লিকেই জানুন **ঢাকা (Dhaka)**, **চট্টগ্রাম (Chattogram)**, **সিলেট (Sylhet)**, **রাজশাহী (Rajshahi)**, **খুলনা (Khulna)**, **বরিশাল (Barishal)**, **রংপুর (Rangpur)**, **ময়মনসিংহ (Mymensingh)**, **কক্সবাজার (Cox's Bazar)**, **গাজীপুর (Gazipur)** ও **কুমিল্লার (Cumilla)** আবহাওয়া।
- 🌴 **মৌসুমি জলবায়ু বিশ্লেষণ**: বর্ষার বৃষ্টিপাত, কালবৈশাখী ঝড়, গ্রীষ্মের তাপদাহ, নদী অববাহিকার আর্দ্রতা ও শীতের কুয়াশার নির্ভরযোগ্য মেট্রিক্স।
- 🔍 **সহজ অনুসন্ধান**: যে কোনো জেলা, উপজেলা বা শহরের নাম লিখে সার্চ করুন।
- 🌓 **ডার্ক ও লাইট থিম**: চোখের সুরক্ষার জন্য আধুনিক ডার্ক এবং লাইট মোড টগল।
- 🎯 **স্বয়ংক্রিয় জিপিএস লোকেশন**: এক ক্লিকেই আপনার বর্তমান অবস্থানের তাৎক্ষণিক আবহাওয়া নির্ণয়।
- 🌡️ **সেলসিয়াস ও ফারেনহাইট রূপান্তর (°C / °F)**: তাৎক্ষণিক ইউনিট কনভার্সন।
- 📊 **বিস্তারিত আবহাওয়া ডেটা**: আর্দ্রতা (Humidity), বাতাসের গতি ও কম্পাস দিক (Wind Direction), বায়ুচাপ (Pressure), দৃশ্যমানতা (Visibility), ইউভি সূচক (UV Index) এবং সূর্যোদয় ও সূর্যাস্ত।
- ⏰ **২৪ ঘণ্টার টাইমলাইন**: প্রতি ৩ ঘণ্টার পূর্বাভাস স্লাইডার।
- 📅 **৫ দিনের পূর্বাভাস কার্ড**: সর্বোচ্চ ও সর্বনিম্ন তাপমাত্রার ভিজ্যুয়াল কালার বার।
- ⚡ **স্মার্ট অফলাইন ডেমো মোড**: এপিআই কি ছাড়াও তাৎক্ষণিক কার্যকর ও নির্ভুল সিমুলেশন সাপোর্ট।

## 🛠️ প্রযুক্তি (Tech Stack)

- **মার্কআপ**: Semantic HTML5 (ARIA Accessibility & OpenGraph support)
- **ডিজাইন**: Vanilla CSS3, CSS Custom Properties, Glassmorphism (`backdrop-filter`), Responsive CSS Grid & Flexbox
- **লজিক**: Vanilla ES6+ JavaScript (Modular Async/Await, Fetch API, LocalStorage)
- **আইকন**: [Lucide Icons](https://lucide.dev/)
- **ফন্ট**: [Google Fonts (Hind Siliguri, Outfit, Plus Jakarta Sans)](https://fonts.google.com/)
